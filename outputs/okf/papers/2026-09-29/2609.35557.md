# The Compiler May Read It, the Agent May Not: Keeping Part of a Research Code Away from a Coding AgentTitle:

## 概要 (Abstract)
The compiler must read modules a physics-based solver cannot build without; the coding agent must not read that intellectual property. The harness does not ship that rule.
